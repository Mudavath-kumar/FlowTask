# Build TaskFlow — Full-Stack Task Management & Analytics Platform

Build a production-quality full-stack web application called **TaskFlow**.

TaskFlow is a minimal, modern task management platform where authenticated users can create, organize, track, search, filter, sort, and analyze their tasks.

The application must be fully functional, responsive, secure, and deployable.

---

## 1. Technology Stack

### Frontend

* React.js
* Vite
* JavaScript only
* React Router
* Axios
* CSS / CSS Modules
* Use a lightweight chart library such as Recharts for analytics
* No TypeScript
* No unnecessary UI framework

### Backend

* Node.js
* Express.js
* JavaScript
* MongoDB
* Mongoose
* JWT authentication
* bcrypt for password hashing
* dotenv
* CORS

### Deployment

* Frontend → Vercel
* Backend → Render
* Database → MongoDB Atlas
* Source code → GitHub

# 2. Design Theme

Create a **minimal premium SaaS dashboard**.

The visual style should feel similar to modern productivity applications.

### Design principles

* Minimal
* Clean
* Professional
* Spacious
* Fast
* Accessible
* Mobile responsive
* No unnecessary gradients
* No excessive animations
* No visual clutter

### Color system

Light mode:

* Background: soft off-white
* Surface: white
* Primary text: near-black
* Secondary text: muted gray
* Borders: subtle gray
* Primary action: dark/black
* Success: green
* Warning: amber
* Danger: red

Dark mode:

* Background: near-black
* Surface: dark gray
* Text: white/light gray
* Borders: subtle dark gray
* Primary action: white with dark text

Use CSS variables so the theme can be switched easily.

# 16. Authentication API

### Signup

```http
POST /api/auth/signup
```

Request:

```json
{
  "name": "Kumar",
  "email": "kumar@example.com",
  "password": "password123"
}
```

Response:

```json
{
  "success": true,
  "message": "Account created successfully",
  "token": "...",
  "user": {
    "id": "...",
    "name": "Kumar",
    "email": "kumar@example.com"
  }
}
```

### Login

```http
POST /api/auth/login
```

Return JWT token and safe user information.

---

# 17. JWT Authentication

Protect all task routes.

Expected flow:

```text
React
 ↓
Authorization: Bearer TOKEN
 ↓
Express
 ↓
JWT verification
 ↓
req.user
 ↓
Controller
```

If token is missing or invalid:

```text
401 Unauthorized
```

---

# 18. Task APIs

Implement:

```http
GET    /api/tasks
POST   /api/tasks
GET    /api/tasks/:id
PUT    /api/tasks/:id
PATCH  /api/tasks/:id/status
DELETE /api/tasks/:id
```

All routes require authentication.

Users must only be able to access their own tasks.

If a user attempts to access another user's task:

```text
403 Forbidden
```

or return:

```text
404 Not Found
```

without leaking information.

# 39. Final Quality Bar

The final application should NOT look like a basic CRUD assignment.

It should feel like a small real SaaS product.

Prioritize:

1. Correct functionality
2. Security
3. Clean architecture
4. Good UX
5. Responsive design
6. Professional visual design
7. Deployment
8. Documentation

Do not add unnecessary features until all assignment requirements are complete.

Build the application incrementally and ensure each part works before moving to the next part.
